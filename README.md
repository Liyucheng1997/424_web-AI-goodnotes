# 墨记 InkMind · 网页版手写笔记 + AI 康奈尔笔记

类似 GoodNotes / Notability 的网页笔记软件，界面采用苹果式简约设计。核心亮点：**给一段音频，本地语音识别后交给 Claude Opus 5.5，自动整理成“手写版”康奈尔笔记**，生成的每个字、荧光笔、波浪线、手绘图示都是普通笔记元素，之后可以自己随意修改。

## 功能

**书写（GoodNotes 式）**
- 钢笔（支持触控笔压感）、荧光笔、橡皮擦、套索（移动 / 缩放 / 改色 / 复制 / 删除）、形状（矩形、椭圆、直线、箭头，可选手绘风格）、文字框、插入图片（也可直接 Ctrl+V 粘贴截图）、抓手
- **按住成形**：画完笔画后笔尖按住不动约半秒，自动拉直线条或规整成矩形 / 椭圆
- 纸张模板：康奈尔（默认）、横线、方格、点阵、空白；三种纸张颜色
- 多页：缩略图栏、添加 / 复制 / 删除 / 调整页序；Ctrl+滚轮缩放、适应宽度
- 撤销 / 重做、仅触控笔书写（防手掌误触）、深色模式
- 导出整本 PDF、导出单页 PNG
- 书库：搜索标题和内容、收藏、重命名、创建副本、删除；全部数据存在浏览器 IndexedDB，自动保存

**AI 记笔记（Notability 式录音 + AI）**
- 三种输入：上传音频/视频文件、现场录音（带实时字幕，可以边录边手写）、粘贴文字
- 语音识别：浏览器内运行 Whisper（WebGPU 加速，不支持时自动退回 WASM），音频不离开本机；中文结果自动转为简体
- Claude Opus 5.5 把转录整理成康奈尔笔记：线索栏问题、要点、荧光笔标重点、波浪线强调、流程图 / 对比表 / 思维导图等手绘图示、底部总结和关键词
- 可选详细程度、笔记语言、手写字体（霞鹜文楷、马善政、站酷快乐体、Caveat 等）、额外要求
- 每个笔记本保存录音，可回放、重新识别、复用转录

## 运行

需要 Node.js 18+。

```bash
npm install
```

配置 Claude API Key（二选一）：
- 复制 `.env.example` 为 `.env`，填写 `ANTHROPIC_API_KEY=...`
- 或者启动后在网页「设置」里填写（只保存在你的浏览器里，经本地服务转发给 Anthropic）

开发模式（前端 5173 + 后端 8787）：

```bash
npm run dev
```

打开 http://localhost:5173

生产模式（打包后由同一个 Node 服务托管）：

```bash
npm run build
npm start
```

打开 http://localhost:8787

## 说明

- 第一次识别会下载 Whisper 模型并缓存在浏览器中（Small 约 250MB）。国内网络访问 HuggingFace 不稳定时，「设置 → 下载源」可切换到 hf-mirror 镜像（默认自动检测）。
- 实时字幕使用浏览器自带的语音识别（Chrome / Edge），需要联网；停止录音后也可以用 Whisper 再精确识别一遍。
- 没有 API Key 时，AI 面板里的「离线预览示例笔记」可以直接看到排版效果。

## 目录

```
src/ai/            Whisper Worker、录音、Claude 调用、康奈尔手写排版引擎
src/Editor.jsx     笔记编辑器
src/Library.jsx    书库首页
```
